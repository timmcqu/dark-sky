FAQ

Hardware Only or Ready-to-Run?

Hardware Only is the kit as the shop ships it — you load the listener image. Ready-to-Run is the same hardware. We load the listener firmware on the board before it ships. Extra business day. Ships from us after we load it.

Is Thread or Zigbee a Remote ID radio?

No. Remote ID (ASTM F3411 / OpenDroneID) is Wi-Fi + Bluetooth LE only. Thread / Zigbee / 802.15.4 does not carry Remote ID. The extra radio is for mesh backhaul between site nodes.

Can I add an external antenna?

Not on this board. This variant is PCB antenna only. There is no u.FL, w.FL, or SMA on the board. The site listener module is the kit with a w.FL antenna chain.

Is a battery included?

No. USB-C only. We refuse LiPo add-ons.

How is this different from the $79 color scanner or the $129 alert board?

Different chip class, a flanged box, and a mesh radio for backhaul. No color display and no OLED in this kit. The $79 board is a one-piece color scanner. The $129 kit is a receive board plus a separate OLED and a small box.

Is this a spectrum scanner?

No. An ESP32 is not a spectrum analyzer. Spectrum awareness stays on the TinySA Ultra scan page.
