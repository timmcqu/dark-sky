FAQ

Is this the $399 Raspberry Pi receiver?

No. That kit is a Raspberry Pi 5 (4 GB) with official 27 W power, the official case, a Remote ID board, a radio, and a 1090 SMA whip. This starter is a Raspberry Pi 4 (4 GB) with official 15 W power, the Remote ID board, and the radio. No case. No 1090 whip. The dipole is in the wideband kit.

Is there a 1090 whip in the box?

No. The radio ships with a dipole. If you want a 1090 SMA whip in the kit, the $399 Pi 5 receiver includes one. The standalone 1090 antenna is also live.

Is there a battery or a flashed microSD?

No. Official USB-C 15 W. No Li-ion and no UPS HAT. Hardware only — you load your own software. Not Fusion Sensor.

Is the radio V4?

No. The radio is the current V3-class USB radio with dipole. V4 is not listed.

How does this differ from the $199 ADS-B kit?

The $199 kit is a Remote ID board, a radio, 1090 and 978 whips, and a small hard case — no computer. This kit is a Pi 4 kit with Remote ID and a radio. No 1090 whip, no 978, no case.

Hardware Only or Ready-to-Run?

Hardware Only ships as the factory kit. You load the receiver image. Ready-to-Run is the same hardware — we load the image before it ships. Extra business day.
