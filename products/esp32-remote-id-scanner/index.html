FAQ

Hardware Only or Ready-to-Run?

Hardware Only is the board as the shop ships it — you load the listener image. Ready-to-Run is the same hardware. We load the listener firmware on the board before it ships. Extra business day. Ships from us after we load it.

Is this the $39 bare board?

No. The $39 SKU is a bare ESP32 receive board with no display. This is a different, one-piece color-display ESP32 board.

Is this the $129 Remote ID alert board?

No. The $129 kit is a bare receive board plus a separate assembled OLED and a small weatherproof box. This SKU is one board with the color display already on it. No box in this order.

Is a battery included?

No. USB-C only. We refuse LiPo add-ons. There is no Li-ion in the box.

Does it transmit?

No. Receive only. Detection / airspace awareness.

Is this a spectrum scanner?

No. An ESP32 is not a spectrum analyzer. The spectrum scanner is the TinySA Ultra on the scan page.
