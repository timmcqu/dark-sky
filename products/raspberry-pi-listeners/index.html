  • $399 / $479 receiver — step to Pi 5, official 27 W, official case, and a 1090 SMA whip. Hardware Only or Ready-to-Run.
  • $549 / $629 professional — keep the Pi 5 sit and add 978 plus the dual-channel filter. The filter is the expensive line. Hardware Only or Ready-to-Run.

Do not buy two Remote ID Pi sits to “upgrade.” Buy the step you need. The $199 ADS-B + Remote ID kit is still the no-computer option.

FAQ

Did you remint the $399 Raspberry Pi receiver?

No. That SKU and that page stay. The starter is a Pi 4 without a case or a 1090 whip. Professional adds 978 and a filter. Outdoor is a weather box and a different antenna class.

Which kit has a Remote ID board?

Starter $279, the live $399 receiver, professional $549, and outdoor $649. The $299 feeder does not. The $199 ADS-B kit does, and has no Pi.

Do you ship a flashed microSD or Fusion Sensor?

No. Hardware only. You load your own software. Fusion Sensor is a separate flashed sit we set up with you. None of these kits are that.

Is any of this V4?

No. Listen radios in this line are the current V3-class USB radio with dipole. V4 is not listed.
