FAQ

Is this Fusion Sensor?

No. Fusion Sensor is the $2,000 / $4,500 flashed sit we set up with you. This is the bare receive board. You load your own software.

Is there a battery?

No. USB-C only. We refuse Li-ion add-ons.

Does it show IDs on a screen?

No. This SKU is the board. The $129 Remote ID Alert Board adds an assembled OLED and a weatherproof box.

No. Receive only. It listens for broadcast Remote ID. Receive only.

How is this different from the $99 starter?

The starter is this board plus the USB listen radio and dipole. This page is the board alone.
