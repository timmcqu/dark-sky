FAQ

Hardware Only or Ready-to-Run?

Hardware Only ships as the factory board. You load the receiver image. Ready-to-Run is the same hardware — we load the firmware before it ships. Extra business day.

Which rung should I buy?

Need IDs in a terminal — bare board. Need them on a screen — color scanner or OLED kit. Need several nodes — mesh. Need a wall or mast — site kit.

Is there an ESP32 spectrum board?

Spectrum is the TinySA Ultra. These boards do Remote ID over Wi-Fi and Bluetooth.

Do you include a battery?

No. USB-C only. We refuse LiPo add-ons on every ESP32 rung.

Where are the Raspberry Pi kits?

On the Raspberry Pi Receivers collection.
