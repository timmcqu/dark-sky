What each hears

An ESP32 receiver hears cooperative Remote ID on Wi-Fi and Bluetooth. ASTM F3411 / OpenDroneID broadcasts from aircraft that are transmitting them. That is the pocket screen. That is the desk box. That is the wall node.

A Raspberry Pi kit hears that layer because the kit includes a Remote ID board. It also hears 1090 ADS-B through a USB receive radio. 978 UAT is an add-on or a feeder kit. ADS-B is crewed transponders, not drones.

Remote ID is a drone broadcast when the aircraft is cooperative. ADS-B is a crewed transponder broadcast on 1090, and 978 UAT in the United States. Do not read an ADS-B track as a drone. Do not read a Remote ID track as a crewed aircraft.

If the aircraft is dark, or RID-off, it is not in the picture. Quiet is not a clearance. Rings on the map are scale, not detection range.

The Raspberry Pi ADS-B Feeder hears 1090 and 978 only. No Remote ID board. Do not buy it to hear drones. Ready-to-Run $369.

Add 978 to a 1090 Pi you already own with the 978 add-on. Do not force a dual-band kit if you only need UAT.

Do not stack two Remote ID computers

Pick one Pi. The indoor kit already has a Remote ID board. A second Pi does not give you a second layer. It gives you a second computer.

Add an ESP32 only as a second node or a pocket scanner. A door box while the Pi stays in the closet. A color screen in the bag while the site kit stays on. That is a node. That is not two site computers.

A common order is the indoor Pi for the named site, then the pocket receiver for the walk. One computer on the wall. One screen in the hand.

Mesh is several ESP32 nodes sharing a picture. Each node still hears cooperative Remote ID on Wi-Fi and Bluetooth. Mesh is not ADS-B. Mesh is not a substitute for a Pi kit.

Do not buy two Ready-to-Run Pi kits to cover one room. Do not buy a pocket ESP32 and a desk ESP32 and a site ESP32 for the same doorway. Pick the form. Add a node only when the site has a second place to stand.

ESP32 cannot do ADS-B

A wall ESP32 is still Remote ID. A desk ESP32 is still Remote ID. A mesh node is still Remote ID. Wi-Fi and Bluetooth only.

FAQ

Can an ESP32 hear ADS-B?
No. 1090 and 978 are a radio on the Raspberry Pi kit. Pocket Remote ID hears cooperative Remote ID on Wi-Fi and Bluetooth only.
Does a quiet picture mean the air is empty?
No. Quiet is not a clearance. Dark or RID-off aircraft are not in the picture.
Should I buy two Remote ID computers?
No. Pick one Raspberry Pi kit for the site. Add an ESP32 only as a second node or a pocket scanner.
What does the ADS-B feeder hear?
1090 and 978 aircraft broadcasts. It has no Remote ID board. ADS-B is crewed transponders, not drones.
Is the shop price Hardware Only or Ready-to-Run?
The shop sticker is Ready-to-Run. Hardware Only is the same kit. You load the image.
Will this find a dark aircraft?
No. The ESP32 hears cooperative Remote ID. The Pi kit adds cooperative 1090 ADS-B. Neither finds dark or RID-off aircraft.
