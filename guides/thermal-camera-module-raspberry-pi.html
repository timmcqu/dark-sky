Buying guide

Thermal camera module for Raspberry Pi

A thermal camera module for Raspberry Pi is a heat-contrast board, not a handheld. Dark Sky sells 32×24 I2C at $149 and 160×120 USB at $649. Visible CSI is Camera Module 3.

Shop receivers Raspberry Pi kits

Which module

  • 32×24 I2C thermal camera module — $149. Pi or MCU.
  • 160×120 USB thermal camera module — $649. Nineteen thousand heat points.
  • Visible, not thermal: Raspberry Pi Camera Module 3 — $59.
  • Pick it up: handheld thermal, 256 class — $549.

Collection: Camera modules. A Pi 5 CSI port needs a 22-to-15 adapter (about $3, not sold here).

FAQ

Is this medical?

No. Heat contrast only. Not a reading you use on a patient.

Does the 32×24 replace a handheld?

No. It is a module for a kit. Handhelds have a cell and a grip.

Will it detect a drone by heat?

It is a site picture layer. It is not a Remote ID receiver.
