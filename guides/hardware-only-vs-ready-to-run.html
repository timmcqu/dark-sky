Hardware Only vs Ready-to-Run

Every Dark Sky Remote ID receiver and Raspberry Pi ADS-B receiver offers two checkouts: Hardware Only, or Ready-to-Run. Same radios. The difference is who loads the receiver image.

When to pick Hardware Only

You already flash ESP32 boards or Raspberry Pi cards. You want the ESP32 Remote ID scanner or a Raspberry Pi Remote ID receiver kit as the shop ships it.

When to pick Ready-to-Run

You want the kit to boot. We load the receiver image on a 64 GB card (Pi) or the ESP32 firmware (board) before it leaves. Extra business day. Still receive only.

FAQ

Is Ready-to-Run different hardware?

No. Same Remote ID receiver or Raspberry Pi ADS-B kit. We load the receiver image.

Does Hardware Only include a blank card?

Pi kits are the computer and radios. A blank 64 GB card is a separate SKU if you need one.

Can I convert later?

Yes. Load the image yourself, or buy Ready-to-Run on the next board.
