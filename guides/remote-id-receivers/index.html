What a receiver hears

A Remote ID receiver is a listen radio. It sits still. It does not fly. Dark Sky Systems LLC sells receive-only kits. When an aircraft is transmitting the required US Remote ID message, the receiver can decode it.

ASTM F3411 is that message set. OpenDroneID is the public format over Wi-Fi and Bluetooth. The radio in the kit determines which of those paths it can hear. We map fields as sent. We do not invent a track.

Typical fields, when the aircraft sends them: aircraft ID, ID type, latitude, longitude, altitude, heading, speed, operator location, and self-ID text. ID type is serial, registration, session, or network ID as broadcast. Operator location is the location in the message. We do not find the operator by direction-finding. We do not invent a house.

US Remote ID sits under 14 CFR Part 89. The receiver receives broadcasts. It does not enforce Remote ID. It is not a substitute for it. A craft that must broadcast, and is broadcasting, can appear. A craft that is not broadcasting cannot.

Power is USB-C on the pocket and board kits. The Raspberry Pi kits are a host computer plus a Remote ID board. Console is a map on a laptop you already own. In every case the radio is receive-only. Transmit is none.

What it does not hear

Dark or RID-off aircraft are not in the picture. If the radio is off, there is no message. A quiet map is not a clearance of those aircraft. Quiet means no live cooperative tracks. That is all it means.

Analog video-only craft are not OpenDroneID. An FPV flyer that sends video and no Remote ID does not appear on the receiver. The receiver is not a camera. It is not a video decoder. It is not a spectrum analyzer. It does not sweep every signal on 2.4 GHz and call the sweep an aircraft.

This is not a jammer. Dark Sky Systems LLC does not jam, spoof, or intercept. No take-over. No effects. Antenna gain is a radio. Rings on a map are scale. We do not publish a detection range.

ADS-B is a different layer. Crewed transponders on 1090 MHz, and in the US on 978 MHz. Some Raspberry Pi kits hear that layer as well. The ADS-B feeder kit hears only that layer. See Remote ID and ADS-B below.

Dark Sky Systems LLC is not a licensed security company. Not dispatch. If people are in danger, call 911 first.

Remote ID and ADS-B

Two layers. Do not mix them. Remote ID is the drone broadcast on Wi-Fi and Bluetooth. ADS-B is crewed aircraft transponders. 1090 MHz is Mode S. 978 MHz is US UAT. A quiet Remote ID picture says nothing about ADS-B. A quiet ADS-B picture says nothing about drones.

Raspberry Pi Receiver and Raspberry Pi Receiver Outdoor hear cooperative Remote ID and 1090 ADS-B in one kit. That is the named-site pair.

Raspberry Pi ADS-B Feeder is 1090 and 978 only. No Remote ID board. It will not list a drone. Buy it to feed aircraft broadcasts. Do not buy it as a Remote ID receiver.

Dark Sky Console plots Remote ID from the radios you plug in. It plots 1090 and 978 ADS-B when a USB receive radio is connected. Cyan on the map is ADS-B. It is not scored as unknown Remote ID. You still supply the radios.

FAQ

What does a Remote ID receiver hear?
Cooperative ASTM F3411 / OpenDroneID broadcasts. Aircraft ID, position, and operator fields when the aircraft is transmitting. Wi-Fi and Bluetooth, radio dependent. The receiver does not fly.
Does it find every drone?
No. Cooperative Remote ID only. Dark or RID-off aircraft are not in the picture. Analog video-only craft with no Remote ID are not in the picture. Quiet is not a clearance.
Do you jam or take over drones?
No. Receive-only. Dark Sky Systems LLC does not jam, spoof, or intercept. No take-over. No effects.
Is this a spectrum analyzer?
No. A Remote ID receiver decodes the required message when it is on the air. It is not a sweep of every signal on 2.4 GHz.
What about analog video or FPV?
If the aircraft is not transmitting Remote ID, the receiver has nothing to decode. Analog video is not OpenDroneID.
Does the receiver fly?
No. It sits on a desk, in a bag, on a mast, or next to a laptop. It is a listen radio.
Is ADS-B the same as Remote ID?
No. Remote ID is the drone broadcast. ADS-B is crewed aircraft transponders on 1090 MHz and, in the US, 978 MHz. Different layers. Some Raspberry Pi kits hear both. The ADS-B feeder kit has no Remote ID board.
Does the ADS-B feeder hear Remote ID?
No. The Raspberry Pi ADS-B Feeder is 1090 and 978 only. No Remote ID board.
Pocket, indoor Pi, outdoor, or Console?
Pocket is a color screen in the hand. Indoor Pi is a named-site kit with Remote ID and ADS-B. Outdoor Pi is the weather box on a mast, plant, or fence. Console is the operations map on a laptop you already own. Pick one computer. Add the other only as a second node.
What is Ready-to-Run?
The shop sticker. We load the image before it ships. Hardware Only is the same kit. You load the image. Ready-to-Run is labor, not a radio markup.
Is the ESP32 Receiver Board in stock?
Yes. The USB-C ESP32-S3 board is the in-stock board. No screen, no battery, no box. Pair it with a host you already own.
Do you publish a detection range?
No. Antenna gain is a radio. Rings on the map are scale. Not direction-finding. Not a range.
If people are in danger?
Call 911 first. Dark Sky Systems LLC is not dispatch and not a licensed security company.
