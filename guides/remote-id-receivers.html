What a Remote ID receiver does

A Remote ID receiver is a radio for ASTM F3411 / OpenDroneID broadcasts. It does not fly. It does not jam. It shows IDs, positions, and operator fields when an aircraft is transmitting.

Pair it with a Raspberry Pi ADS-B receiver if you also want 1090 / 978 crewed-aircraft broadcasts on the same kit.

How to choose

Start with the job. Pocket IDs on a screen: an ESP32 Remote ID scanner. A desk or mast kit that also hears ADS-B: a Raspberry Pi Remote ID receiver kit. Factory board vs we-load-it: Hardware Only vs Ready-to-Run.

What it does not do

Cooperative broadcasts only. A Remote ID receiver does not detect dark or RID-off aircraft. ADS-B is crewed transponders, not drones. Dark Sky Systems LLC is not a licensed security company.

FAQ

Does a Remote ID receiver see every drone?

No. It hears cooperative Remote ID broadcasts. Quiet or RID-off aircraft do not appear.

Do I need a Raspberry Pi?

No. An ESP32 Remote ID scanner is enough for IDs on a screen. Add a Pi when you want ADS-B and a kit that stays on.

Hardware Only or Ready-to-Run?

Hardware Only is the factory kit; you load the receiver image. Ready-to-Run is the same hardware — we load it before it ships.
